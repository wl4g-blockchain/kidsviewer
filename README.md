# KidsViewer - 儿童视界

一款专为拯救儿童玩手机而设计的智能家长控制应用，通过教育挑战来限制屏幕时间并促进学习。

## 🌟 主要功能

### 家长控制功能
- **时间限制**: 支持 10/15/20/30/40 分钟自动锁定
- **学习解锁**: 通过回答教育问题来解锁继续观看
- **多学科支持**: 数学、语文（繁体字识别）、英语等
- **个性化设置**: 根据孩子年龄段调整难度
- **使用统计**: 详细的每日使用报告和学习进度

### 儿童学习功能
- **智能题库**: 动态随机生成适合年龄的问题
- **进度跟踪**: 记录学习表现和健忘曲线
- **趣味界面**: 专为儿童设计的友好 UI
- **多语言支持**: 中文和英文界面

## 🚀 技术架构

- **前端**: React 18 + TypeScript + Vite
- **桌面端**: Electron 28 (跨平台支持)
- **状态管理**: Zustand
- **样式**: Tailwind CSS
- **国际化**: react-i18next
- **图标**: Lucide React

## 📱 平台支持

1. **iPad/iOS** (优先实现)
2. **Android**
3. **桌面端** (Windows/macOS/Linux)

## 🚀 快速开始

### 环境要求
- Node.js 18+
- npm 或 yarn

### 安装依赖
```bash
npm install
```

### 开发模式
```bash
# 启动 Vite 开发服务器
npm run dev

# 启动 Electron 开发模式
npm run electron-dev
```

### 构建应用
```bash
# 构建 Web 版本
npm run build

# 构建 Electron 应用
npm run electron-build

# 构建并打包分发版本
npm run dist
```

## 📖 使用说明

### 家长设置流程
1. 注册/登录家长账号
2. 添加孩子信息（姓名、年龄段）
3. 配置时间限制和问题设置
4. 设置允许访问的视频平台 URL
5. 监控使用报告和学习进度

### 儿童使用流程
1. 选择孩子账号登录
2. 观看家长设置的视频内容
3. 时间到后自动锁定
4. 回答教育问题解锁继续观看
5. 查看学习进度和成就

## 🌍 国际化支持

- **中文**: 简体中文界面，支持繁体字识别题目
- **English**: 英文界面，适合双语学习

## 🔧 配置说明

### 时间限制选项
- 学前儿童 (2-4岁): 10-15分钟
- 小童 (4-6岁): 15-20分钟  
- 大童 (6-12岁): 20-40分钟

### 问题类型
- **数学**: 基础计算、数字识别
- **语文**: 繁体字识别、词语理解
- **英语**: 基础词汇、简单语法

## 📊 数据存储

- **本地存储**: LocalStorage (离线使用)
- **云端存储**: 标准 API 接口 (可选)
- **数据同步**: 支持多设备数据同步
